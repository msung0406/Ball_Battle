## 변수 규칙

캐릭터는 기술을 여러 개 가질 수 있으며, 기술마다 쿨타임이 따로 돌아감.

변수 이름은 `기술명` + `항목`으로 설정. 변수값이 기술의 실제 값이며, 변수 외의 요인으로 인해서 실제 적용되는 값이 달라지는 경우를 최소화하고, 필요에 의해 실제 적용되는 값이 달라질 경우 주석으로 표기.

| 항목 | 의미 |
|---|---|
| `Charge` | 차지 시간(초) |
| `Cooldown` | 쿨타임(초) |
| `Damage` | 피해 |
| `KnockbackForce` | recoil이 없을 때 밀어내는 힘 |
| `KnockbackSpeed` | recoil이 있을 때 밀어내는 속도 |
| `DashSpeed` | 돌진 속도 |
| `DashTime` | 돌진 유지 시간(초) |
| `ThrowSpeed` | 투사체 속도 |
| `Track` | `true`: 적을 따라 조준, `false`: 무작위 방향으로 조준 |
| `Telegraph` | `true`: 조준 방향을 점선으로 보여 줌 |

이 항목에 들어가지 않고 특정 기술에만 쓰는 값에는 주석으로 의미를 표기.
